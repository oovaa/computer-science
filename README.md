## 🎯 Overview

**OSSU Computer Science** is a **complete, free, self-taught education in Computer Science** using online materials. Designed according to [CS 2013](CURRICULAR_GUIDELINES.md) curriculum guidelines for undergraduate CS degrees.

> **Not just career training** — A proper, well-rounded grounding in concepts fundamental to all computing disciplines.

---

## 🎓 Curriculum Structure

### 📚 **Prerequisites**
- High school math: algebra, geometry, pre-calculus
- [Pre-college math guide](https://ossu.dev/precollege-math)

### 🏫 **Intro CS** (1 course)
| Course | Duration | Effort | Prerequisites |
|--------|----------|--------|---------------|
| [Introduction to CS & Programming (Python)](coursepages/intro-cs/README.md) | 14 weeks | 6-10 hrs/week | High school algebra |

### 🎯 **Core CS** (Required — ~3 years equivalent)

#### **Core Programming**
| Course | Topics |
|--------|--------|
| [Systematic Program Design](https://www.edx.org/course/how-to-code-simple-data) | Functional programming, design recipes, testing |
| [Design of Computer Programs](https://www.udacity.com/course/design-of-computer-programs-cs212) | Design patterns, testing, requirements |
| [Software Construction](https://ocw.mit.edu/courses/6-005-elements-of-software-construction-fall-2011/) | OOP, testing, design patterns, static/dynamic typing |
| [Functional Programming](https://www.coursera.org/learn/progfun1) | SML, recursion, pattern matching, types |
| [Compilers](https://www.coursera.org/learn/compilers) | Lexing, parsing, type checking, code gen |

#### **Core Math**
| Course | Topics |
|--------|--------|
| [Linear Algebra](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/) | Vectors, matrices, eigenvalues, SVD |
| [Calculus](https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/) | Limits, derivatives, integrals, series |
| [Probability](https://ocw.mit.edu/courses/6-041sc-probabilistic-systems-analysis-and-applied-probability-fall-2013/) | Random variables, Bayes, distributions |
| [Statistics](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2014/) | Inference, regression, hypothesis testing |

#### **CS Tools**
| Tool | Course |
|------|--------|
| Git/GitHub | [Git & GitHub](https://www.edx.org/course/introduction-to-git-and-github) |
| Linux/CLI | [The Missing Semester](https://missing.csail.mit.edu/) |
| SQL | [Intro to SQL](https://www.khanacademy.org/computing/computer-programming/sql) |

#### **Core Systems**
| Course | Topics |
|--------|--------|
| [Computer Architecture](https://ocw.mit.edu/courses/6-004-computation-structures-spring-2017/) | Digital logic, ISA, pipelining, caches |
| [Operating Systems](https://ocw.mit.edu/courses/6-828-operating-system-engineering-fall-2012/) | Processes, threads, virtual memory, FS |
| [Networks](https://www.coursera.org/learn/computer-networking) | TCP/IP, routing, congestion control, DNS |
| [Databases](https://ocw.mit.edu/courses/6-830-database-systems-fall-2010/) | Relational model, SQL, transactions, NoSQL |

#### **Core Theory**
| Course | Topics |
|--------|--------|
| [Algorithms](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/) | Divide & conquer, DP, greedy, graphs |
| [Complexity](https://ocw.mit.edu/courses/6-045j-automata-computability-and-complexity-spring-2011/) | P vs NP, reductions, complexity classes |
| [Cryptography](https://www.coursera.org/learn/crypto) | Symmetric/asymmetric crypto, protocols |

#### **Core Security**
| Course | Topics |
|--------|--------|
| [Computer Systems Security](https://ocw.mit.edu/courses/6-858-computer-systems-security-fall-2014/) | Memory safety, web security, crypto |

#### **Core Applications**
| Course | Topics |
|--------|--------|
| [Machine Learning](https://www.coursera.org/learn/machine-learning) | Supervised/unsupervised, neural nets |
| [Computer Graphics](https://ocw.mit.edu/courses/6-837-computer-graphics-fall-2012/) | Rendering, ray tracing, animation |

#### **Core Ethics**
| Course | Topics |
|--------|--------|
| [Ethics](https://www.edx.org/course/ethics-technology-and-engineering) | Professional ethics, privacy, AI ethics |

### 🚀 **Advanced CS** (Electives — choose your path)

| Track | Courses |
|-------|---------|
| **Advanced Programming** | [Parallel Computing](https://ocw.mit.edu/courses/6-172-performance-engineering-of-software-systems-fall-2018/), [Distributed Systems](https://www.coursera.org/learn/distributed-programming-in-java) |
| **Advanced Systems** | [Advanced OS](https://ocw.mit.edu/courses/6-828-operating-system-engineering-fall-2012/), [Computer Networks](https://www.coursera.org/learn/computer-networking) |
| **Advanced Theory** | [Quantum Computing](https://www.edx.org/course/quantum-computing-fundamentals), [Advanced Algorithms](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2008/) |
| **Advanced Security** | [Applied Crypto](https://www.coursera.org/learn/applied-crypto), [Web Security](https://ocw.mit.edu/courses/6-858-computer-systems-security-fall-2014/) |
| **Advanced Math** | [Convex Optimization](https://www.coursera.org/learn/convex-optimization), [Information Theory](https://ocw.mit.edu/courses/6-441-information-theory-spring-2016/) |
